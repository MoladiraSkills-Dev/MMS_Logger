📑 Export Parameters

ℹ️ Timesheet Export Specifications

Generated timesheets strictly adhere to MolāDira Skills compliance standards:

  • Floor Times Mandatory: Start and End times on PDF and CSV are drawn directly from the audited Floor Time calculations.
  • Standard Anchors: Non-edited shifts anchor to 08:00 - 17:00 (13:00 on Saturdays) with 1-hour lunch deducted for shifts over 5 hours.

  • Leave Abbreviations: Leave days are dynamically annotated as SL (Sick), AL (Annual), or FL (Family).
  • Sign-off Section: Includes mandatory Employee Signature and Manager/Supervisor verification spaces.

🏗️ Decoupled Serverless Architecture

Core Architecture

The MMS Logger utilizes a decoupled serverless architecture separating presentation, business logic, and persistence into isolated, secure tiers:

Tier Technology Responsibilities
Frontend HTML5, Vanilla JS, CSS3 Hosted on GitHub Pages; static presentation; client session management.
API Gateway Google Apps Script (Code.gs) Processes all HTTP POST API requests; executes as script owner; server-side secrets.
Database Google Sheets SSDB 8 structured tables storing users, logs, summaries, leave, and device checkouts.
🔒 Zero Client Secrets: LocationIQ API keys, database spreadsheet keys, and salted user password hashes never touch the client browser.

⏱️ Shift Engine & Smart Floor Times

BCEA Compliant

Enforces standard working hours while preventing unauthorized overtime and dockings under BCEA South African labor standards:

Parameter Weekday (Mon - Fri) Saturday
Shift Span 08:00 AM – 17:00 PM 08:00 AM – 13:00 PM
Clock-In Floor ≤ 08:00 → 08:00 | > 08:00 → Rounded to nearest 5m (e.g. 08:07 → 08:05)
Clock-Out Floor Bound to 17:00 Bound to 13:00
1h Lunch Deduction Auto-deducted if shift > 5 hours Zero lunch deduction
Overtime Lock Locked to 0 mins on standard shifts; unlocked only via Admin Audit
⚠️ Admin Audit Overrides: Manual adjustments set isAdminEdit = true, bypassing standard 17:00 anchors and calculating true overtime.

🛡️ Defensive Auto-Failsafes

Integrity Engine

Autonomous server-side routines maintain database cleanliness without requiring manual supervisor intervention:

  • Failsafe 1 - Abandoned Shift Auto-Closure (autoClosePreviousShifts): When an employee clocks in, any previous open shift (In Progress) is automatically terminated at standard closing time (17:00 / 13:00) with location "System Auto-Logout Failsafe".
  • Failsafe 2 - Clock-Out Guard: Employees cannot clock out in the afternoon unless a valid morning clock-in was recorded for that date. Rogue clock-outs are blocked.
  • Failsafe 3 - Single Action Guard: Prevents duplicate clock-ins or duplicate clock-outs on the same date.
🚨 Data Integrity: Ensures weekly and monthly summaries never calculate multi-day runaway shifts if a device loses battery.

📍 4-Tier Geolocation Telemetry

GPS Verification

Every attendance action acquires high-accuracy device coordinates and resolves physical street addresses through a multi-tier fallback pipeline:

Tier Provider / Engine Resolution Target
Tier 1 LocationIQ API High-precision street, suburb, and postal address.
Tier 2 OpenStreetMap Nominatim Secondary reverse geocode with corporate User-Agent.
Tier 3 BigDataCloud Client Keyless tertiary locality, city, and province fallback.
Tier 4 Coordinate String Clean GPS Coordinates (lat, lon) representation.
🔄 Re-Resolve Addresses: Administrators can click "Re-resolve Addresses" on the Activity Logs tab to back-fill any rate-limited entries.

🗄️ Database Schemas (8 Core Tables)

Google Sheets SSDB

All persistent data is stored across 8 structured tables created and styled automatically via setupDatabase():

  • Users: Email, Name, Salt, SHA-256 Hash, Role (Employee/Admin), Status (Verified/Blocked).
  • Activity_Logs: Immutable telemetry trail with Log ID, GPS coordinates, timestamp, and address.
  • Daily_Summaries: Matched shift records with raw times, floor times, net duration, and status.
  • Weekly_Summaries: ISO-8601 week aggregates (YYYY-Www) with compliance totals (≤ 45h).
  • Monthly_Summaries: Calendar month (YYYY-MM) compensation and billing aggregates.
  • Leave_Requests: Leave applications (SL, AL, FL, Special) and approval tracking.
  • Device_Requests: Hardware checkouts, serial numbers, expected returns, and release status.
  • Admin_Settings: Administrator authorization registry and role definitions.
⚡ Setup Engine: Run setupDatabase() in Google Apps Script to instantly scaffold the entire database architecture.

JSON RPC Gateway

📑 BCEA Compliance Timesheets

Audit Ready

Generates legally verifiable timesheets for Department of Employment and Labour inspections:

  • Official PDF Timesheet: Includes corporate letterhead, BBBEE Level 1 badge, shift breakdowns, ordinary hours, overtime, and mandatory Employee + Supervisor signature lines.
  • Raw CSV Export: Structured data export for direct import into corporate payroll systems (e.g. Sage, Pastel, SimplePay).
  • Batch ZIP Archiving: Compiles and packages individual PDF timesheets for every active contractor in one click.
✍️ Legal Sign-Off: Preserves physical and digital accountability with dedicated verification spaces.

❓ Troubleshooting & Diagnostics

SOP & Maintenance

Standard operating procedures for rapid diagnostic resolution of common environmental errors:

GPS Denied: Instruct user to click padlock icon in browser address bar and set Location to "Allow". Click "Test GPS" to verify.
API Downgrade / 302: Ensure Web App deployment is set to "Execute as: Me" and "Access: Anyone".
Missing Sheets: In Google Sheets, run ⚡ MMS Logger Tools → Setup / Repair Database Tables.
Historical Shifts Unsynced: Click "Sync Summaries from Logs" on the Daily Shifts tab.
🛠️ Maintenance Menu: The Google Sheet custom menu provides 1-click tools for re-resolving addresses and resetting floor times.
